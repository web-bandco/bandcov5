# Brighton and Co V5 - Version 5.2.0

There are a number of key changes in v5.2.0:

- **Shop Page Refresh** - Introducing individual pages for each storefront (a page for Vinted and eBay Stores)
- **Product Card Improvements** - The appearance of product cards has been refined, with item condition, sizing and description being hidden by default, enabling a cleaner look, whilst displaying more items to the user
- **Added Breadcrumbs** - With v5.2.0, breadcrumbs (the bit that for example has Home > Shop > Vinted Store), this is to improve the ease of navigation and improve the site's overall usability.

There are also a few more minor changes and improvements:

- Backend updates
- General refinements.

# Brighton and Co V5 - Version 5.3.0

There are a number of key changes in v5.3.0:

- **Brand New Shop Page** - One page for SHOP: B&Co for both eBay and Vinted items.
- **Product Description Pages** - Each item now has its own Product Description Page (PDP), with more photos of items and more details.

There are also a few more minor changes and improvements:

- Backend updates
- General refinements.

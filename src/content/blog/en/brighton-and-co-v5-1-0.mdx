# Brighton and Co V5 - Version 5.1.0

There are a number of key changes in v5.1.0:

- **Photography Page Refresh** - Introducing individual pages for each holiday (a page for Prague, Pefkos/Rhodes, and London photos)
- **Astro Content Collections** - Fully implemented Astro Content Collections for easier management of existing content
- **Increased Modularity** - With the changes in v5.1.0, the modularity of the photography page has been increased and improved, enabling more content to be more easily added in the future.

There are also a few more minor changes and improvements:

- Backend updates
- Implementing Google Analytics in more places

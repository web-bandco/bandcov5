# The Launch of Brighton Version 5

Brighton and Co Version 5 (B&Co V5) is a major improvement an upgrade over the old site, bringing with it vast changes and improvements to the site's performance, functionality and most importantly - its appearance.

Below are a few of the key changes that you'll notice.

## Performance Improvements

- **Optimised image delivery** - Lazy loading for images to reduce load times
- **Using Ready to Go Components** - Using components from shadcn and DaisyUI
- **Using the Latest Version of Astro** - Initially beginning on Astro 6, B&Co V5 now runs on Astro 7 and is actively updated
- **Using less Javascript** - Prioritising Astro wherever possible, to ensure B&Co V5 remains as lightweight as possible

## Functionality Improvements

- **Accessibility Prioritised** - Accessibility has been heavily emphasised prior to the launch of B&Co V5, using data from PageSpeed Insights to ensure accessibility is consistently scoring 100 on both mobile and desktop
- **Consistency** - Using components primarily from shadcn - as well as some from DaisyUI - to ensure a consistent, high quality user experience across B&Co V5
- **Content Management** - Using content management to quickly and actively update the shop page, with changes to existing items, as well as adding new items for sale

## A New Look

- **A New Style** - The whole site has been completely overhauled, with a new design, which is consistent and higher quality
- **Consistent Styling** - Hero sections which unify each page into one consistent design identity
- **More interactivity and Visuals** - More visual content and more interactivity, especially with photo carousels showcasing my photography, as well as items on SHOP: B&Co.

All of the above is only a small sample of the work that has been going on for nearly three months in getting Brighton and Co Version 5 ready for launch.

Of course, there are still improvements, tweaks and changes that can - and will - be made.

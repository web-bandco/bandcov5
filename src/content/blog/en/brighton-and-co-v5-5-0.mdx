# Brighton and Co V5 - Version 5.5.0

There are a number of key changes in v5.5.0:

- **Completely New Colour Scheme** - Continuing the site's October refresh and regeneration, a new colour theme has been chosen to spruce up and improve the attractiveness of the entire site, as well as improving accessibility.
- **Visual Upgrades** - Liquid Glass has been improved, along with new animations for lightboxes for images. As well, the text carousel on the home page has been improved and upgraded.

There are also a few more minor changes and improvements:

- Backend updates
- General refinements.
